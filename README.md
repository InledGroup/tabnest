# <img src="public/tabnest.png" width="40" height="40" align="center" /> TabNest


Tabnest es una extensión de navegador, diseñada para Chrome y Firefox, que ofrece una página de inicio con acceso rápido a marcadores y carpetas de marcadores, noticias, televisión y radio.   
Puedes añadir teclas especificas y atajos para los marcadores que más quieras.  

**TV, radio, marcadores, noticias y busqueda en un solo lugar**   

Más de 400 canales, medios y radios nacionales. Añade los que quieras.   
Marcadores ya predefinidos opcionales por si quieres no tener que preparar todo.   
Busqueda con IA integrada con Google AI Mode.   

## Comandos

### Testear
```bash
npm run start:firefox
```
o
```bash
npm run start:chrome
```
### Empaquetar
```bash
npm run package:chrome
```
o
```bash
npm run package:firefox
```
